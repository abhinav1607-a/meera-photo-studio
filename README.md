# Meera Photo Studio

Premium photography and cinematography portfolio website for Meera Photo Studio, Raipur, Chhattisgarh.

## Project brief
This repository is intended to host a responsive portfolio website for Mukesh Agrawal and Meera Photo Studio, including:
- Photography and videography portfolio galleries
- Weddings, pre-wedding shoots, birthdays, events, portraits and drone cinematography
- Kazima Album Making showcase
- WhatsApp, phone and email contact actions
- Secure admin dashboard for managing photos, videos, services, site content and enquiries
- Persistent storage and database integration
- Responsive, accessible, SEO-ready public pages

## Suggested stack
- React + Vite + TypeScript
- Tailwind CSS
- Framer Motion
- Supabase Auth, PostgreSQL and Storage

## Local development
Once the application files and dependencies have been added:

```bash
npm install
npm run dev
```

## Environment and security
Use a local `.env` file for development, keep real secrets out of Git, and configure server-side/database policies before enabling uploads or enquiries. See `.env.example` once the application configuration is added.
